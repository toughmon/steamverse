# 개인정보처리방침 (초안)

> 상태: **초안** (2026-11-18). 배포 형태는 **공개 웹 서비스**로 정했다. 공개 전에 [ ] 표시(서버 위치·연락처)를 채우고 사이트에 게시한다.
>
> 근거: Steam Web API 이용 약관 §2(비공개 사용자 데이터를 다루면 처리방침 게시, 저장 국가 명시), 개인정보 보호법 제20조. 자세한 내용은 [STEAM_COMPLIANCE.md](STEAM_COMPLIANCE.md) P5·P6.

## 1. 처리하는 정보

| 대상 | 항목 | 출처 |
|---|---|---|
| 이용자 본인 | SteamID, 닉네임, 계정 생성일, Steam 레벨, 보유 게임, 게임별 플레이 시간(전체·최근 2주), 마지막 플레이 날짜, 업적 수(해금/전체) | Steam Web API (공개 프로필) |
| 이용자의 Steam 친구 | SteamID, 닉네임, 친구가 된 날, **이용자와 같이 가진 게임**의 플레이 시간 | Steam Web API (친구의 공개 프로필) |
| 게임 | 이름, 개발사·퍼블리셔, 장르, 태그, 출시년도, 가격, 이미지 주소 | Steam 상점, SteamSpy (개인정보 아님) |

- Steam에서 **공개(Public)로 설정된 정보만** 받는다. 비공개로 설정된 정보는 받지 않고 다른 방법으로 알아내지 않는다
- Steam 아이디·비밀번호는 받지 않는다
- 친구의 전체 라이브러리는 저장하지 않는다. 이용자와 겹치는 게임만 남긴다

## 2. 이용 목적

이용자 본인이 자기 게임 라이브러리를 그래프·차트·탐사 화면으로 보는 것. 그 밖의 목적(광고, 마케팅, 판매, 분석 판매, AI 학습)에는 쓰지 않는다.

## 3. 보관 위치와 기간

- 위치: 서비스 서버 — 서버 위치: [ ] ______ (국가) — 배포 설정 `SERVER_REGION`과 같게. 앱 정보 패널에 자동 표시
- 기간: 라이브러리·친구 정보는 받은 뒤 **20분**이 지나면 삭제. 게임 정보(개인정보 아님)는 7일
- 탐사 기록·화면 설정은 이용자 브라우저(또는 앱) 저장소에만 있다

### 로그인과 쿠키

- 로그인은 Steam 로그인(OpenID)으로만 한다. 비밀번호는 Steam 페이지에만 입력되고, 이 서비스는 Steam이 확인해 준 SteamID만 받는다
- 로그인 상태를 유지하려고 `sv_session` 쿠키(SteamID와 발급 시각, 서명됨, 30일)를 쓴다. 로그인 과정에서 10분짜리 `sv_login_state` 쿠키를 잠깐 쓴다. 둘 다 HttpOnly이며 광고·추적에 쓰지 않는다
- 로그아웃하면 쿠키를 지우고 그 계정의 라이브러리·친구 정보 캐시도 바로 지운다

## 4. 제3자 제공

하지 않는다. 처리를 맡기는 곳도 없다.

## 5. 친구의 정보에 대해 (개인정보 보호법 제20조)

친구 정보는 친구 본인이 아니라 Steam을 통해 받은 정보다. 친구 본인이 요청하면 지체 없이 다음을 알리고, 요청에 따라 처리를 멈춘다.
- 수집 출처: Steam Web API (친구 본인이 공개로 설정한 Steam 프로필)
- 처리 목적: 2장
- 처리 정지를 요구할 권리가 있다는 사실

처리 정지 요청을 받으면 그 SteamID를 수집 제외 목록에 넣는다. (공개 서비스 단계에서 구현 — COMPLIANCE_PLAN.md 4장)

## 6. 지우는 방법

- 앱 정보 화면(상단 `i` 버튼) → **내 데이터 지우기** → 서버 캐시의 라이브러리·친구 정보와 브라우저의 탐사 기록·설정을 즉시 지운다
- Steam 쪽에서 프로필을 비공개로 바꾸면 다음 동기화부터 그 정보를 받지 않는다
