# Steam 약관·저작권 준수 규약

> 조사일: 2026-11-18 · 다음 재확인: 공개 배포 직전, 그리고 그 뒤 6개월마다
>
> 이 문서는 Valve 공식 문서와 국내 법령·판례를 읽고 만든 **프로젝트 내부 규약**이다. 법률 자문이 아니다. 공개 서비스·유료화 전에는 전문가 검토를 받는다.
>
> 규칙 앞의 **[필수]** 는 예외 없이 지킨다. **[공개 전]** 은 나 혼자 로컬에서 쓰는 동안은 유예되지만, 다른 사람이 쓰거나 볼 수 있게 되기 전에(웹 공개·앱 배포·스크린샷 홍보 포함) 반드시 해결한다.

---

## 0. 한눈에 보기 — 절대 하지 않는 것

1. Steam 로고·아이콘을 쓰지 않는다 (Valve 별도 라이선스 없이는 권리가 없다)
2. Valve·Steam과 제휴·공식·인증인 것처럼 보이게 하지 않는다
3. Steam API 키를 브라우저·배포 앱·저장소·로그에 내보내지 않는다
4. 사용자 Steam 비밀번호를 받거나 저장하지 않는다
5. Steam 계정으로 로그인한 상태에서 자동화(봇·스크립트)하지 않는다
6. 하루 10만 회를 넘겨 Web API를 부르지 않는다. 상점·SteamSpy 요청 간격을 줄이지 않는다
7. 게임 이미지·설명을 내 것처럼 저장·재배포·홍보에 쓰지 않는다
8. 친구 데이터를 그 친구 본인 외의 사람에게 보여 주거나 팔지 않는다
9. Steam 데이터를 팔거나 데이터 묶음으로 내보내 재배포하지 않는다

## 2. Steam Web API 키

| # | 규칙 | 근거 |
|---|---|---|
| K1 | **[필수]** 키는 서버(또는 데스크톱 앱의 메인 프로세스)에만 둔다. 브라우저·렌더러 코드, 응답 본문, 오류 메시지에 절대 넣지 않는다 (지금 `/api/health`처럼 있는지 여부만 알린다) | API 약관 §2: 키를 비밀로 유지하고 제3자와 공유하지 않는다 |
| K2 | **[필수]** 키가 담긴 요청 URL(`?key=...`)을 로그로 남기지 않는다. 외부 요청 오류는 호스트·상태 코드만 기록한다 (`lib/http.ts`의 `UpstreamError` 방식 유지) | 위와 같음 |
| K3 | **[필수]** `.env`는 git에 올리지 않는다 (`.gitignore`에 있음). 키가 커밋·공유되면 즉시 steamcommunity.com/dev/apikey 에서 폐기 후 재발급 | 위와 같음 |
| K4 | **[필수]** 배포하는 데스크톱 앱이나 클라이언트에 **내 키를 넣지 않는다.** 배포판은 사용자가 자기 키를 입력하게 하거나, 내 서버를 거치게 한다 | API 약관 §2·§13: 키는 나와 내 앱에 한정되고 양도할 수 없다 |
| K5 | 키 발급 양식에 적은 도메인·앱 이름과 실제 서비스가 맞게 한다. 이름을 바꾸면(T4) 발급 정보도 갱신한다 | API 약관 §1 |

## 3. 호출량·부하

| # | 규칙 | 근거 |
|---|---|---|
| L1 | **[필수]** Steam Web API는 키당 **하루 10만 회** 이하. 공개 서비스에서는 하루 호출 수를 세어 80%에서 경고하고 새 동기화를 멈춘다 | API 약관 §2 |
| L2 | **[필수]** 호스트별 요청 간격을 줄이지 않는다. 지금 값이 하한이다 | 아래 표 |
| L3 | **[필수]** 429나 한도 초과 응답을 받으면 그 호스트 전체를 일정 시간 멈춘다 (`throttle.pause()`). 재시도 폭주 금지 | API 약관 §2: Steam 서비스를 저하시키지 않는다 |
| L4 | **[필수]** 캐시를 먼저 본다. 같은 데이터를 짧은 간격으로 다시 받지 않는다 | 위와 같음 |
| L5 | **[필수]** Steam 데이터는 그 사용자가 요청할 때만 받는다. 사용자가 없는 계정을 미리 긁어 두는 배경 크롤링을 하지 않는다. 공개 서비스에서는 **Steam 로그인한 본인 계정만** 조회하고, SteamID를 입력해 남의 계정을 조회하는 기능을 두지 않는다 (`PUBLIC_MODE=1`) | API 약관 §2 |

| 출처 | 공식 여부 | 현재 간격 | 근거 |
|---|---|---|---|
| Web API (`api.steampowered.com`, 키 사용) | 공식 | 0.12초, 429 시 30초 정지 | 하루 10만 회 (API 약관) |
| 상점 태그 (`IStoreBrowseService`, `IStoreService`) | 공식 호스트, 키 없음 | 0.3초, 429 시 60초 | 문서화된 한도 없음 |
| 상점 `store.steampowered.com/api/appdetails` | **비공식** (상점 웹 내부용) | 1.6초, 429 시 90초 | 공식 한도 없음. 커뮤니티 실측 약 200회/5분/IP |
| 업적 전 세계 달성률 (`GetGlobalAchievementPercentagesForApp`) | 공식 호스트, 키 없음 | 0.25초, 429 시 60초 | 게임 단위 공개 통계. 7일 캐시를 모든 이용자가 같이 씀 |
| SteamSpy | 제3자 | 1.1초, 429 시 60초 | SteamSpy 문서: 대부분 초당 1회, `all` 요청은 60초에 1회. 데이터는 하루 한 번 갱신 |

- **[필수]** 비공식 상점 API는 언제든 막히거나 바뀔 수 있다. 막혀도 앱이 죽지 않게 한다 (지금처럼 실패 시 샘플·캐시로 대체)
- **[필수]** SteamSpy 데이터는 같은 게임을 24시간 안에 다시 받지 않는다 (지금 7일 캐시)
- **[필수]** SteamDB 등 다른 서비스는 긁지 않는다. SteamDB는 데이터 전체 재배포와 AI 학습 사용을 명시적으로 금지한다

## 4. Steam 계정·로그인·자동화

| # | 규칙 | 근거 |
|---|---|---|
| A1 | **[필수]** 사용자의 Steam 아이디·비밀번호를 입력받지 않는다. 가로채거나 저장하지 않는다 | API 약관 §2 · Web API 문서 · 구독 약관 §1.C |
| A2 | **[필수]** 로그인이 필요해지면 **Steam OpenID 2.0만** 쓴다 (`https://steamcommunity.com/openid/`). 버튼은 Valve가 제공하는 "Sign in through Steam" 이미지를 고치지 않고 쓴다 | Steamworks 인증 문서 |
| A3 | **[필수]** Steam 계정 세션·쿠키로 로그인해서 하는 작업(커뮤니티 페이지 긁기, 거래, 인벤토리·마켓 자동화, 업적·카드 파밍 등)을 하지 않는다. 공개 API의 읽기 요청만 한다 | 구독 약관 §4.B–D: 스크립트·봇 등 자동화 금지, 위반 시 계정 제재 |
| A4 | **[필수]** 멀티플레이 게임에서 이점을 주는 기능을 만들지 않는다 | API 약관 §2 |

## 5. 데이터·개인정보

Steam 데이터에는 남의 개인정보(친구의 SteamID·닉네임·보유 게임·플레이 시간)가 들어 있다. 공개 프로필 정보라도 한국 개인정보 보호법의 보호 대상이다 (대법원 2016. 8. 17. 선고 2014다235080: 공개된 개인정보는 정보주체가 공개한 취지 안에서만 동의 없이 처리할 수 있다).

| # | 규칙 | 근거 |
|---|---|---|
| P1 | **[필수]** 공개(Public)로 설정된 정보만 쓴다. 비공개라서 API가 안 주는 정보를 다른 방법으로 알아내지 않는다. 지금처럼 비공개면 경고만 띄운다 | Steam 개인정보처리방침 5.4: 공개 프로필 정보는 API로 접근할 수 있고, 그 밖의 정보는 사용자가 프로필 설정으로 통제한다 |
| P2 | **[필수]** 친구 데이터는 **요청한 본인 화면에서만** 보여 준다. 공개 프로필·공유 카드·스크린샷 홍보물에는 친구 이름·SteamID를 넣지 않는다 (집계 숫자만) | PLAN.md 10장 · 개인정보 보호법 |
| P3 | **[필수]** 친구 데이터는 화면에 필요한 만큼만 받는다: 이름, 친구 맺은 날, 내 라이브러리와 겹치는 게임의 플레이 시간 (지금 `library.ts` 방식). 친구의 전체 라이브러리를 저장하지 않는다 | 최소 수집 원칙 |
| P4 | **[필수]** 캐시(`apps/server/.cache`)는 git에 올리지 않고(`.gitignore`에 있음), 남에게 넘기지 않는다. 라이브러리 캐시는 짧게(지금 10분) 유지한다 | API 약관 §2 |
| P5 | **[공개 전]** 개인정보처리방침을 게시한다: 무엇을 받는지(Steam 공개 데이터, 친구 공개 데이터), 어디에 얼마나 저장하는지(저장 국가 포함), 삭제 방법, 수집 출처가 Steam이라는 점 | API 약관 §2: 비공개 사용자 데이터를 다루면 처리방침 필수, 저장 국가 명시 · 개인정보 보호법 제20조 |
| P6 | **[공개 전]** 삭제 요청 경로를 만든다. 본인 계정 삭제 시 즉시 파기하고, 친구 등 제3자가 요청하면 수집 출처와 목적을 알리고 처리를 멈춘다 | 개인정보 보호법 제20조: 정보주체 외의 경로로 받은 정보는 요구 시 출처·목적·처리정지권을 알려야 한다 |
| P7 | **[필수]** Steam 데이터로 원치 않는 마케팅(메일·알림 대량 발송 등)을 하지 않는다 | API 약관 §2 |
| P8 | **[필수]** Steam 데이터는 "있는 그대로" 제공한다고 고지한다. SteamSpy 추정치는 추정치라고 표시한다 | API 약관 §2 (§7·§8과 비슷한 면책) · SteamSpy 소개: 표본으로 추정하므로 정확하지 않다 |
| P9 | **[필수]** 서비스를 접거나 Valve가 이용을 끝내면 받은 Steam 데이터와 Steam 관련 표기를 모두 지운다 | API 약관 §11 |
| P10 | 사용자가 약관을 크게 어기는 것을 알게 되면 webapi@valvesoftware.com 으로 알린다 | API 약관 §2 |

## 6. 게임 콘텐츠 저작권 (이미지·이름·설명)

게임 표지·스크린샷·로고·설명문의 저작권은 각 **개발사·퍼블리셔**에 있고, Steam 상점 자료는 Valve와 그 라이선스 제공자의 것이다 (구독 약관 §2.F–G). 우리에게 사용 허락이 있는 것은 아니므로, "게임을 알아보게 하는 최소한의 표시"로만 쓴다. 국내에서는 검색 서비스의 작은 썸네일 이미지 게시가 공정이용으로 다뤄진 사례가 있다 (대법원 2006. 2. 9. 선고 2005도7793, 저작권법 제35조의5). 다만 이 원칙이 우리 쓰임새 전부를 덮어 주지는 않는다.

| # | 규칙 | 근거 |
|---|---|---|
| C1 | **[필수]** 게임 이미지는 Steam CDN 주소를 그대로 불러 쓴다 (지금 방식). 우리 저장소·서버·배포 파일에 이미지 파일을 저장하거나 묶어 넣지 않는다 | 구독 약관 §2.G: 복제·배포 금지 |
| C2 | **[필수]** 게임 이미지를 우리 로고·앱 아이콘·홍보 이미지·스토어 등록 이미지·광고에 쓰지 않는다. 홍보 스크린샷은 **시연 모드**(상단 데이터 출처 → 시연)로만 찍는다 | 위와 같음 · 상업적 이용 금지 §2.G(iii) |
| C3 | **[필수]** 게임 이미지에서 2차 저작물을 만들어 파일로 남기거나 내보내지 않는다. 탐사 뷰의 도트 행성은 화면에 그릴 때 메모리에서만 만들고 저장·다운로드·공유 기능을 붙이지 않는다 | 위와 같음 |
| C4 | **[공개 전]** 탐사 뷰가 표지 그림을 도트로 바꾸는 것은 원본을 변형하는 일이다. 공개판에서는 ① 표지 없이 장르 색 행성으로 그리거나 ② 원본을 바꾸지 않은 썸네일만 따로 보여 주는 방식 중 하나로 정한다 | 위와 같음 (변형 이용은 공정이용 판단에 불리) |
